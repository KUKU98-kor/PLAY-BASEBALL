# PLAY BASEBALL Prototype

팀에 가입하지 않아도 날짜·지역·희망 포지션을 선택해 생활야구 경기에 참가하는 모바일 우선 PWA 프로토타입입니다.

## 실행

```bash
pnpm install
pnpm dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 구현된 흐름

- 지역별 경기 필터
- 경기 카드와 모집 현황
- 경기 상세 바텀시트
- 희망 포지션 최대 3개 선택 및 지망 순서 표시
- 참가 신청 완료 피드백
- 모바일·태블릿·데스크톱 반응형 UI
- 키보드 포커스와 reduced-motion 대응

## 아직 연결되지 않은 기능

- 회원가입과 인증
- 실제 데이터베이스
- 결제·환불
- 운영자 도구
- 실시간 알림과 날씨

구현 순서와 개발 에이전트용 프롬프트는 [docs/IMPLEMENTATION_PROMPT.md](docs/IMPLEMENTATION_PROMPT.md)를 참고하세요.

# PLAY BASEBALL

> 팀을 찾지 마세요. 경기만 고르세요.

PLAY BASEBALL은 팀에 가입하지 않아도 원하는 날짜와 지역의 생활야구 경기를 찾아 개인으로 참여할 수 있도록 돕는 서비스입니다.

## 우리가 해결하려는 문제

사회인야구는 경기 한 번에 많은 인원과 구장이 필요해, 개인이 원하는 날 가볍게 참여하기 어렵습니다. 참가자는 여러 커뮤니티에서 경기 자리를 찾아야 하고, 경기 운영자는 참가자를 모집하고 일정을 관리하는 데 많은 시간을 씁니다.

PLAY BASEBALL은 경기 탐색과 참가 과정을 더 쉽고 분명하게 만드는 것을 목표로 합니다.

## 주요 사용자

- 정기적인 팀 활동은 부담스럽지만 야구 경기에 참여하고 싶은 사람
- 기존 팀 외에 추가 경기를 원하는 사회인야구 선수
- 생활야구를 처음 경험하고 싶은 입문자
- 경기 참가자를 효율적으로 모집하고 싶은 운영자

## 기본 이용 흐름

1. 지역과 날짜를 기준으로 경기를 찾습니다.
2. 경기 장소, 시간과 참가 조건을 확인합니다.
3. 원하는 포지션을 선택해 참가를 신청합니다.
4. 경기 안내를 받고 현장에서 함께 야구합니다.

## 서비스 방향

PLAY BASEBALL은 생활야구 참가자가 팀 소속 여부와 관계없이 실제 경기를 더 쉽게 발견하고 참여할 수 있는 환경을 만들고자 합니다. 작은 지역에서 사용자 경험을 확인한 뒤 더 많은 지역으로 서비스를 확장할 계획입니다.
