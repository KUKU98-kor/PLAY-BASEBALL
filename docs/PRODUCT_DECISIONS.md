# 제품 결정 기록

## 현재 결정

- 첫 구현은 앱스토어 네이티브 앱보다 배포와 검증이 빠른 모바일 우선 PWA로 진행한다.
- 첫 지역은 대전·세종으로 한정한다.
- 핵심 상품은 개인이 결제하고 참여하는 PLAY MATCH다.
- 첫 MVP의 중심 행동은 경기 탐색 → 상세 확인 → 포지션 1~3지망 → 참가 신청이다.
- 경기 운영자용 복잡한 기능, 캐치볼 커뮤니티, 정교한 기록과 자체 충전지갑은 뒤로 미룬다.

## 레퍼런스에서 확인한 패턴

- 소셜 스포츠는 사용자가 원하는 시간과 장소의 경기를 바로 선택하는 흐름이 중요하다.
- 현장 운영자, 매너 관리와 수준 데이터가 반복 참가의 신뢰를 만든다.
- 운영자 없는 경기 유형은 공급을 늘릴 수 있지만 장비·규칙·책임 안내가 더 명확해야 한다.

## 가장 큰 사업 가설

대전·세종 사용자가 팀 가입 없이 한 경기에 실제 비용을 지불하고, 경기 경험에 만족해 다시 참가하는가?

## 개발보다 먼저 함께 측정할 지표

- 경기당 모집 완료 시간
- 포지션별 충원율, 특히 투수와 포수
- 참가 신청 대비 결제 완료율
- 취소·노쇼·대체충원율
- 1~3지망 포지션 배정률
- 첫 경기 후 30일 내 재참가율
